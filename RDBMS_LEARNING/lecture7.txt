Sub Queries

1. Get List of all Indian States
- Find Code of India
- Extract Records from state where country_code = ?
- Or Better make use of Sub Query
select * from state where country_code = (select code from country where name="India")

2. Get List of all American States
select * from state where country_code = (select code from country where name="USA")

3. Get list of all Indian cities
select code,name from city where state_code in (select code from state where country_code in (select code from country where name="India"))

4. Get emp_id and name of all American employees
select emp_id,first_name,last_name from employee where emp_id in (select emp_id from employee_address where city_code in (select code from city where state_code in (select code from country where name='USA')))
